## 🔐 과제 8: 패스키(WebAuthn) 보안 금고 핵심 기능
- **공개/비공개 영역 분리 (T08-C13)**: 포트폴리오의 공개 영역과 패스키 전용 비공개 영역 사이에 눈에 띄는 보안 경계선 배치
- **비밀번호 없는 순수 비대칭 인증 (T08-C21~23)**: 서버에는 오직 공개키만 저장되며, 개인키는 사용자의 기기 보안 칩(TPM/Secure Enclave)에서 나가지 않음
- **일회용 챌린지 및 재전송 공격 방어 (T08-C19~20, 카드 3)**: 매 로그인마다 고유한 난수 질문을 발급하고 검증 즉시 파기하여 재전송 공격 원천 차단
- **기기 분실 대비 다중 패스키 관리 (카드 4)**: 패스키를 2개 이상 등록하고, 분실 기기를 삭제하더라도 남은 패스키로 안전하게 로그인 가능
- **엄격한 서버 측 접근통제 (T08-C16~18)**: 로그인하지 않은 상태의 직접 API 요청은 401 Unauthorized로 차단되며, HTML 소스 내 비공개 데이터 유출 0건
- **실시간 보안 검증 콘솔 (Security Inspector)**: 심사관이 클릭 한 번으로 401 차단, Replay 방어, 미등록 패스키 차단을 눈으로 확인할 수 있는 인터랙티브 도구 제공
- **대상 및 목적**: 정보보안 및 보안관제 직무 채용 담당자와 실무진에게 보안 엔지니어로서의 기초 역량, 시스템/네트워크 이해도, 학습 태도 및 직무 열정을 신뢰감 있게 전달하는 자기소개 페이지
- **디자인 컨셉**: 사이버 보안 관제 센터(SOC) 무드의 딥 다크 테마, 미니멀 & 클린 UI, 반응형 인터페이스
- **기술 스택**: HTML5, CSS3 (Vanilla CSS), Git & GitHub Pages

## 🌟 핵심 강점 및 검증 근거 (상황 · 행동 · 결과)

실제 팀 프로젝트 [혼밥비서 (Honbabbiseo)](https://github.com/gksxogksxo1001-sketch/Honbabbiseo) 개발 기록(`LOG.md`)을 바탕으로 작성되었습니다.

1. **책임감 & 한계 돌파 (맡은 바는 내 수준을 넘어 최선)**
   - **상황**: 수동 재료 입력 방식으로 인한 서비스 이탈 우려
   - **행동**: 공공데이터 식약처 API 연동(`nutrition-api.js`), 냉장고 점수 알고리즘, 영수증 Vision AI 일괄 등록 파이프라인 구축
   - **결과**: 5대 영양소 자동 판별 및 영수증 한 장으로 수십 개 재료 일괄 등록 완성

2. **주인의식 & 몰입 (내 일처럼 자부심을 가지고 수행)**
   - **상황**: 브라우저 기본 alert 창으로도 통과되나 모바일 사용성 저하
   - **행동**: 기본 팝업 전면 제거 후 커스텀 모달 전면 구현, 모바일 터치 제스처(`touchstart/move/end`) 스와이프 인터랙션 코딩
   - **결과**: PC와 모바일 모두에서 네이티브 앱 수준의 매끄러운 반응형 UX 달성

3. **적극적 질문 & 지식 체득 (모르는 것을 묻고 내 것으로 흡수)**
   - **상황**: Firestore 비동기 실시간 리스너 및 복합 권한 처리 지식 필요
   - **행동**: 핵심 질문을 구체화하여 피드백 받은 후 `board-api.js`, `chat-api.js`, `follow-api.js` 코어 모듈 직접 설계
   - **결과**: 결함 없는 1:1 실시간 채팅 및 알림, 관리자 시스템 구축 완료
